# DOM Testing

DOM testing means checking how your UI behaves in the browser — verifying that elements render, respond to user actions (like clicks or typing), and update correctly.

DOM = Document Object Model (the structure of your webpage).

In testing, you simulate user interactions (clicks, typing, form submissions).

Vitest works with libraries like React Testing Library or Vue Test Utils to make DOM testing easy.

Instead of testing implementation details, you test what the user sees and does.
