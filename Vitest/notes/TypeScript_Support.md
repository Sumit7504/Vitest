# Vitest: TypeScript Support

Vitest works seamlessly with TypeScript, allowing you to write type‑safe tests. This means your functions and tests benefit from compile‑time type checking, reducing bugs and improving reliability.

TypeScript adds types to JavaScript (like number, string, boolean).

In testing, this ensures you don’t accidentally pass the wrong data to functions.

Vitest automatically understands .ts and .tsx files if your project is set up with TypeScript.

You can test both typed functions and React/Vue components written in TS.
